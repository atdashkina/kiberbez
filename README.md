# ОТЧЕТ ПО ЛАБОРАТОРНОЙ РАБОТЕ

## Тема работы

**Защита данных сегмента АСУ ТП (Сценарий №4)**

---

## Цель работы

Изучить методы обнаружения, анализа и устранения последствий компьютерных атак на сегмент автоматизированной системы управления технологическими процессами (АСУ ТП), а также приобрести практические навыки выявления и устранения уязвимостей в корпоративной инфраструктуре.

---

## Задачи работы

В ходе выполнения лабораторной работы необходимо:

- изучить сценарий атаки на сегмент АСУ ТП;
- выявить используемые злоумышленником уязвимости;
- устранить обнаруженные уязвимости;
- ликвидировать последствия компрометации узлов инфраструктуры;
- провести анализ событий информационной безопасности;
- ознакомиться с работой средств обнаружения атак ViPNet IDS NS, ViPNet TIAS и Security Onion.

---

# 1. Описание сценария атаки

В соответствии со сценарием злоумышленник проводит разведку сети и обнаруживает сервер с открытым портом 8080. После этого выполняется эксплуатация уязвимости Axis2, позволяющая получить доступ к серверу приложений.

Получив контроль над сервером, злоумышленник размещает вредоносный backdoor и получает возможность удаленного управления системой.

Далее злоумышленник подготавливает вредоносный PDF-документ, содержащий эксплойт для уязвимой версии программы CoolReaderPDF. Документ доставляется менеджеру через корпоративную систему отчетности.

После открытия документа менеджером злоумышленник получает Meterpreter-сессию на рабочей станции пользователя.

Используя скомпрометированный компьютер менеджера, злоумышленник получает доступ к сегменту АСУ ТП и выполняет эксплуатацию уязвимости в системе IGSS, что приводит к получению полного контроля над SCADA-сервером.
